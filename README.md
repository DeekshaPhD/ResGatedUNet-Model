# ResGatedUNet-Model
Boundary-Aware Crater Segmentation Dataset (Supporting Material)
This repository provides supporting data for the research work:

**"Boundary-Aware Crater Segmentation via ResGatedUNet and Template Matching"**

The dataset is shared to ensure **transparency, reproducibility, and qualitative evaluation** of the proposed crater segmentation framework.

---

## 📌 Contents

The repository contains a representative subset of results generated from the proposed model:

---

## 📊 Dataset Description

- The data consists of **~100 representative samples**
- Includes:
  - Small, medium, and large craters  
  - Dense and sparse crater regions  
  - Challenging cases (faint rims, degraded craters)  
  - Failure cases for transparent evaluation  

---

## 📈 Evaluation Metrics

The file `metrics.csv` includes:

- Precision  
- Recall  
- F1-score  

for each sample image.

---

## 🎯 Purpose

This dataset is provided to:

- Allow reviewers and researchers to **inspect segmentation quality**
- Support **reproducibility of results**
- Provide **benchmark samples** for future research

---

## 🌍 Data Source

The input DEM data is derived from:

- NASA Lunar Orbiter Laser Altimeter (LOLA) Global DEM (118 m/pixel resolution)

---

## ⚠️ Notes

- This is a **subset** of the full dataset used in the study.
- The complete dataset is large and not included here.
- The provided samples are sufficient for **evaluation and verification**.
